# Reactor

**쓸수록 나를 더 잘 아는 AI.** — [tsotlo.com](https://tsotlo.com)

마음, 떠오른 생각, 취향, 하루, 긴 생각을 가볍게 남기면 AI가 곁에서 읽고 반응합니다.
기록이 쌓일수록 AI는 나를 오래 알아온 친구처럼 말하고, 내가 아직 이름 붙이지 않은 나의 모습을 먼저 건넵니다.

일기를 잘 쓰게 하는 앱이 아니라, **기록을 통해 나를 알아가게 하는 서비스**를 목표로 합니다.
연속 기록, 점수, 알림, 광고처럼 사람을 붙잡아 두는 장치는 일부러 쓰지 않았습니다.

## 기능

- **기록과 코멘트** — 8가지 카테고리(마음, 떠오름, 취향, 하루, 나에 대해, 목표, 순간, 생각)로 기록하면, 평가하거나 가르치지 않는 짧은 코멘트가 달립니다. 기록에 말을 덧붙이면 다시 답합니다.
- **오늘의 한마디** — 하루 첫 접속 때 쓸 거리가 떠오르게 하는 질문 하나. 30초 뒤 사라집니다.
- **너에게** — 기록이 쌓이면 가끔, 나를 읽고 먼저 건네는 이야기: 책 한 권, 닮은 역사 속 인물, 나의 가능성, 어울리는 것. 사실 검수를 거쳐 전달됩니다.
- **soft-profile** — 기록에서 뽑아낸 "나는 이런 사람" 카드. 항목을 골라 세로 이미지로 저장하고 공유할 수 있습니다.
- **나의 생각들** — 긴 글('생각')을 모아 읽고, 내가 세상을 어떤 눈으로 보는지 써 줍니다.
- **기억 노트** — AI들이 함께 읽는 이용자별 노트. 오래전 기록까지 기억하되, 힘든 일은 먼저 꺼내지 않습니다.

## 기술

- [Next.js](https://nextjs.org) (App Router) · TypeScript · Tailwind CSS
- [Supabase](https://supabase.com) — 매직링크 로그인, Postgres, 모든 테이블에 행 단위 보안(RLS)
- [Claude API](https://docs.claude.com) — Opus 5 (너에게, soft-profile, 기억 노트 등), Sonnet 5 (코멘트)
- `next/og`로 soft-profile 이미지 생성 · PWA

## AI 규칙 파일에 대해

`comment.md`, `insight.md`, `soft-profile.md` 등 AI의 말투와 원칙을 정하는 규칙 파일은 공개하지 않습니다.
이 저장소에는 각 파일의 역할만 적힌 빈 파일이 들어 있습니다. 직접 실행해 보려면 원하는 지시문을 적어 넣으세요.

## 로컬 실행

```bash
npm install
cp .env.example .env.local   # ANTHROPIC_API_KEY, Supabase URL/키 입력
npm run dev
```

데이터베이스 구조와 보안 규칙은 `supabase/schema.sql`에 있습니다.
